# Decision log

Write a D# entry in DECISIONS.md only when a real choice was made.

- Choice: what was picked.
- Rejected: alternatives actually considered. If one was not measured, say "considered, not measured". Never invent alternatives.
- Reason: one or two lines.
- Evidence: test name, commit, stakeholder answer (time), or measurement.
- Known weakness and failure behavior: what breaks, when, and how it fails.

"AI proposal -> my change": log only changes that happened. Zero is a valid count.
