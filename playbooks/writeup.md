# Write-up checklist

Use the file names the task asks for. Otherwise fill PLAN.md, DECISIONS.md and REPORT.md.

- [ ] Every requirement has an R# row: source, acceptance criterion, status (DONE / PARTIAL / CUT with reason).
- [ ] Traceability: R# -> file:function -> test or smoke line -> commit.
- [ ] Decisions: each D# has choice, rejected alternatives, reason, evidence, weakness.
- [ ] Verification: last test and smoke run, with time and counts copied from real output.
- [ ] Limitations: weakness (file:function) -> risk -> next check.
- [ ] AI collaboration: what was delegated, what I decided, where I changed AI output.
- [ ] Docs match code: no feature described that is not implemented; no number not backed by output.
- [ ] Handoff: current state, next step, open questions in five lines.
