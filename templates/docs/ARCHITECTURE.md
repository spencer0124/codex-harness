## 사용자 동작별 흐름
동작 하나(버튼 하나, 라우트 하나)마다 한 절을 쓴다.

### <동작 이름>
1. 화면 (`src/web/...`):
2. API (`<METHOD> /api/...`, `src/server/...`): zod 검증
3. 도메인 (`src/domain/...`):
4. 저장 (`src/server/store.ts`): 임시 파일에 쓰고 rename
5. 응답과 화면 (또는 내보내기):

실패하면: <어느 단계에서 무엇을 돌려주고, 저장된 버전은 그대로인지>
