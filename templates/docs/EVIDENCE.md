# EVIDENCE

증거 하나에 항목 하나. 출력은 요약하지 않고 그대로 복사한다. 지우거나 고치지 않고 아래에 붙이기만 한다.

## 형식
의도한 red(재현 실패)는 `판정: FAIL` 아래에 `메모: 의도한 red (F# 재현)`을 붙인다. 화면 확인은 `playwright-cli` 명령을 명령 칸에, `docs/screenshots/` 경로와 본 것을 출력 칸에 쓴다.

````markdown
## E1 · HH:MM · U1 · R1
명령: `npm test`
출력 (발췌, 그대로 복사):
```text
<핵심 줄>
```
판정: PASS
````
