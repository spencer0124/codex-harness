# RISKS

결과를 바꾸거나 깨뜨릴 수 있는 상황마다 지금 시스템이 실제로 하는 일을 적는다. 동작은 코드와 테스트로 확인한 것만 쓰고, 테스트가 없으면 근거 칸에 미검증이라고 쓴다.

| # | 상황 | 지금 동작 (파일:함수) | 근거 (테스트 / E#) | 이전 결과는 | 깨지거나 틀린 결과가 보이는 조건 | 다음 점검 |
|---|---|---|---|---|---|---|
| 1 | 조건 변경: 결과를 만든 뒤 입력 조건이 바뀜 | | | | | |
| 2 | 중간 실패: 생성이나 적용이 도중에 실패함 | | | | | |
| 3 | 동시 요청: 두 사용자가 같은 작업을 동시에 요청함 | | | | | |
| 4 | 경계 날짜: 기간 첫날과 마지막 날, 자정을 넘는 시간, 요일이나 월말 같은 특수일 (겹치는 경우마다 4a, 4b …) | | | | | |
| 5 | 숨은 조건: 담당자 답으로 추가된 예외 (C#마다 한 줄) | | | | | |
| 6 | 이상 입력: 누락, 중복, 0, 소수, 범위 밖 값 | | | | | |
| 7 | 로그인 쿠키: 미리보기가 http인데 세션 쿠키에 Secure가 붙어 브라우저가 다시 보내지 않음 | | | | | |
| 8 | CSRF: 다른 사이트나 이웃 미리보기에서 상태를 바꾸는 요청을 보냄 | | | | | |
| 9 | 세션 유실: 서버 재시작(`tsx watch` 포함)으로 메모리 세션이 사라짐 | | | | | |

7~9행은 로그인이 있는 과제에만 쓴다. 로그인이 없으면 지운다.
